## Overview

**MedEye3d.jl** is a cutting-edge Julia library for real-time visualization and annotation of 3D medical imaging data. Built on OpenGL for maximum performance, it specializes in rapid development and segmentation of volumetric medical images including CT, PET/CT, and MRI scans with full support for nuclear medicine data.

Main goal of the package is to conveniently visualize 3D medical imaging to make segmentation simpler.

---

## 🚀 Quick Start

### Installation

```julia
using Pkg
Pkg.add("MedEye3d")
```

### Modern Simplified Usage

For newer, simpler examples together with extras, visit: [MedPipe3DTutorial](https://github.com/jakubMitura14/MedPipe3DTutorial)

```julia
using MedEye3d

# Single CT image
ctImage = ("path/to/ct_scan.nii.gz", "CT")
viewer = MedEye3d.SegmentationDisplay.displayImage(ctImage)
```

## 🚀 Advanced Longitudinal Analysis & AI Subsegmentation

MedEye3d contains a robust suite of tools for processing and visualizing longitudinal Lutetium workflows and robust AI inference.

### 1. Automated Dataset Preprocessing
When dealing with massive longitudinal imaging datasets (e.g. baseline CT, follow-up PETs, and varying SPECT scans across time), MedEye3d can automate the tedious alignment and caching process using ultra-fast HDF5 serialization.

For a comprehensive breakdown of how this pipeline registers images and extracts bone marrow via AI, please read the [Lutetium Workflows Preprocessing Guide](docs/preprocessing_lutetium_workflows.md).

To run the pipeline across your dataset:
```bash
./scripts/preprocessing/preprocess_all_cases.sh data
```

### 2. Interactive Longitudinal Makie App
The main application environment provides a multi-pane `QuadImage` and `5-pane` view that supports side-by-side temporal comparisons.

To launch the app on a preprocessed patient folder (which will load instantly from HDF5):
```bash
julia --project=. scripts/app/run_interactive_mrb.jl data/pat_6_files
```

**Key Features in the App GUI:**
- **Compare Timepoints**: Rapidly flip through longitudinal datasets (PET/CT, SPECT/CT) while maintaining perfect spatial camera alignment.
- **Lesion Navigation**: Jump directly to specific 3D coordinates using the "Next Lesion" metadata GUI panel.
- **Skellytour AI Subsegments**: Dynamically toggle 3D rendering of Cortical Bone Surfaces and Bone Marrow intersecting with your active lesions (generated by `bone_subsegmentation.py`).
- **Modality Windowing**: Specialized density window presets specifically optimized for CT, PET, and SPECT value ranges.

## 📚 Interactive Walkthrough

MedEye3d supports various layout configurations.

### 🔬 Single Image Visualization
Basic visualization of a single 3D volume.
```julia
using MedEye3d
viewer = MedEye3d.SegmentationDisplay.displayImage(("path/to/image.nii.gz", "CT"))
```

### 🎯 Multi-Modal Imaging
Compare two registered modalities simultaneously, e.g., PET and CT. The views are continuously synced.
```julia
using MedEye3d
image1 = ("path/to/ct.nii.gz", "CT")
image2 = ("path/to/pet.nii.gz", "PET")
viewer = MedEye3d.SegmentationDisplay.displayImage((image1, image2))
```

### 🔮 Advanced Visualization
You can also overlay multiple images or use QuadImage display modes. Refer to `test_five_pane.jl` or `run_interactive_mrb.jl` for examples of customizing the `TextureSpec` arrays and the `DisplayMode`.

## 🎮 Interactive Controls

### Mouse Interactions
- **Left Click & Drag**: Adjust contrast / windowing levels dynamically.
- **Right Click & Drag**: Pan across the view.
- **Shift + Scroll**: Zoom in and out.
- **Scroll**: Move through slices (Z-axis navigation).

### Keyboard Shortcuts
- `Space`: Jump exactly to the center of the 3D volume.
- `F3`: Decrease Slice Thickness limit.
- `F4`: Increase Slice Thickness limit (Maximum intensity projection - MIP).
- `1-9`: Toggle active masks/textures (useful for disabling specific segments).
